# 条目同步服务

sync-service 是 vault-sync 内存规则的 PostgreSQL 实现。它只处理已经加密的条目记录。

服务可以知道保险库 ID、条目 ID、revision、删除标记、操作 ID 和游标。它不能知道密码、标题、备注或附件内容，也不会尝试解密 CPI1 里的载荷。

推送按顺序处理一批操作：

- 操作号见过：返回原来的接受或冲突结果。
- 没有服务器记录，且没有 base_revision：接受为新条目。
- base_revision 等于当前版本，且新 revision 更大：接受，游标加一。
- 版本对不上，但服务器已有记录：不覆盖，返回服务器上的密文。
- 声称基于某个版本，但服务器没有这条记录：整批失败，不保留这批里已经看到的写入。

拉取用十进制游标。游标比服务器更新时拒绝。空游标表示从头读取。

账号、设备认证现已接入条目同步服务：账号会话令牌用于账号和设备管理，设备同步令牌用于 push/pull。服务端只保存密码验证材料、令牌哈希、账号设备关系和保险库访问关系，不保存明文密码或令牌。

当前已实现账号注册、登录、登出、设备列表、设备创建、设备撤销和保险库创建。push/pull 要求设备令牌并校验保险库归属。WebAuthn、Redis、附件上传和公网部署仍不在这一版。服务默认只监听 127.0.0.1，不能直接暴露到公网。
