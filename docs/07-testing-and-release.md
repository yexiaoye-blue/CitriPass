# 测试与发布方案

## 1. 加密核心测试

- 固定测试向量和跨平台解密测试；
- nonce 重复检测；
- 密文篡改、截断、重放和跨条目替换测试；
- 错误主密码、错误 Vault Key 和错误版本测试；
- 密钥轮换和格式迁移测试；
- 大文件流式加密、断点和损坏分块测试。

## 2. 同步测试

- 首次同步、增量同步和游标过期；
- 同一条目多设备同时修改；
- 删除与修改冲突；
- 重复提交和网络超时重试；
- 设备撤销后继续同步；
- 服务端返回乱序或重复变更；
- 附件上传中断和恢复。

## 3. 客户端测试

- 自动锁定和切后台；
- Keychain/Keystore 不可用时的降级行为；
- 剪贴板自动清理；
- 浏览器域名匹配和 iframe 防护；
- 无网络、低磁盘空间和应用崩溃恢复；
- 本地模式切换到云端模式。

## 4. 服务端测试

- 认证、设备授权和撤销；
- 权限越界和跨保险库访问；
- 限流、重放和幂等；
- 数据库备份恢复；
- 对象存储越权下载；
- 日志脱敏和密文不透明性。

## 5. 发布门禁

公开 Beta 前必须完成：

- 依赖和供应链扫描；
- 静态分析、动态分析和模糊测试；
- 至少一次独立安全评审；
- 恢复流程演练；
- 从零安装、同步、备份和卸载重装验收；
- 明确的安全漏洞报告渠道。

安全审计不能替代测试，测试也不能替代审计。
